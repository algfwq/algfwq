## About Me

我是 algfwq，也可以叫我「奥利给」。我喜欢把日常里突然冒出来的想法做成真正能跑起来的项目：从桌面端手账式笔记软件，到 QQ 消息总结机器人，再到 Django / WebSocket / Vue / Tauri / AI 工具链的实验，我更享受把一个问题拆开、接上前后端、补齐交互，然后让它变成可用工具的过程。

最近主要在做 [TimeNotes](https://github.com/algfwq/TimeNotes)：一款基于 Wails3 的本地优先桌面笔记软件，包含画布编辑、富文本、图片、贴纸、图层、多页面、阅读预览和多人实时协作。配套的 [TimeNotesServer](https://github.com/algfwq/TimeNotesServer) 用来承接协作链路。

我也在探索 AI 与自动化场景，例如 [QQ-Forward-Summary-Bot](https://github.com/algfwq/QQ-Forward-Summary-Bot)，它基于 Go、NapCatQQ 和 OpenAI 兼容接口，对 QQ 合并转发消息做递归展开与多模态总结。

## What I Work On

- Desktop apps: Go, Wails3, Tauri, React, TypeScript
- AI tooling: OpenAI-compatible APIs, message summarization, embedding and rerank experiments
- Web full stack: Vue, Django, FastAPI, WebSocket, frontend interaction experiments
- Developer tools and learning projects: editor/compiler experiments, Go/Python interop, framework studies
